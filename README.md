# Vaishnavi's World — 23rd Birthday Surprise 💗

A personalized React + Vite birthday website from Mathu to Vaishu, for 12 November 2026.

## Run the website

1. Install [Node.js](https://nodejs.org/) (18+).
2. In a terminal inside this folder, run `npm install`.
3. Run `npm run dev` and open the localhost URL printed by Vite.
4. For a production build, run `npm run build`.

## Add your real photos, music, and video

Place files in `public/media/` using these exact names:

- `memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg`, `memory-4.jpg` — your real friendship/school photos
- `birthday-song.mp3` — music that you have permission to use (visitors must click **Play music**)
- `video-message.mp4` — your recorded birthday message

Until photos are added, the photo cards show soft pink placeholders. If a video hasn't been added, the site shows a gentle fallback message. No personal photos or video were included in the supplied project. Photo files with a different extension must be renamed or updated in `src/App.jsx`.

## What's inside

- A cinematic invitation screen and animated birthday hero
- A Grade 6 to 2026 friendship timeline
- Polaroid photo gallery with click-to-enlarge
- **23 original English reasons** (kept from the supplied app)
- Secret envelope and a long, personal **Tanglish friendship letter**
- Friendship quiz about Saiva Neri class, milk bread toast, and the 23 gifts
- A personal video section
- Final birthday gift reveal
- Responsive layouts, keyboard focus states, and reduced-motion support

The birthday wishes, stories, and school details are taken from the text you supplied; no additional real-life events were invented.

After testing with your photos/video, deploy the project to Vercel or Netlify, then send Vaishu the resulting link on her birthday. Verify the site on a mobile phone first.
